These are verbatim license notices shipped in the checksum-pinned WordNet and OMW packages used by the documented English/Italian/French/Spanish probes. Full datasets remain local under `.miniphi/lexicons/wordnet`; their installer preserves every included component license. Audit reports contain selected lexical entries and glosses.

- [French WOLF](OMW-fra-WOLF.html).
